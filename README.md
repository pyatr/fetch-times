Этот скрипт скачивает файлы (без сохранения) по URL и выводит в консоль время в миллисекундах и размер в байтах после каждого запроса, а также среднее время на запрос, общий скачанный объем данных и среднюю скорость скачивания в мегабайтах.<br><br>
Использование: <code>node index.js "url" count</code>
